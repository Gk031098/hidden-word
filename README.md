# Hidden Word

Find the hidden 5-letter word in 6 tries. A new daily word every day, plus unlimited practice.

**Play it here:** https://gk031098.github.io/hidden-word/

## How to play

Type a 5-letter word and press Enter. The tiles change colour after each guess:

| Colour | Meaning |
|---|---|
| Green | Right letter, right spot |
| Amber | Right letter, wrong spot |
| Grey | Letter is not in the word |

## Levels

| Level | Words | Rules |
|---|---|---|
| Easy | Common everyday words | 2 hints per game |
| Medium | Everyday words | No hints |
| Hard | Less common words | Every clue you find must be used in your next guesses |

## Modes

- **Daily word**: the same word for everyone each day, so you can compare results with friends.
- **Practice**: a new random word every game.

## Features

- Stats for each level: games played, win %, streak and guess chart
- Share button that copies your coloured-squares result for WhatsApp
- Animations, sound effects and background music for each level (both can be turned off)
- Works with the on-screen keyboard or a computer keyboard

Stats and progress are saved in each player's own browser.
